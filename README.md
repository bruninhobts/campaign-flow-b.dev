## 🇧🇷 Português

> **Orquestrador de Marketing com IA e Pipeline Multi-Agente Autônomo**

Pipeline automático baseado em agentes de IA integrados para planejamento de campanhas, redação e geração de posts comerciais com Flux.

### 🚀 Principais Funcionalidades
- **Orquestrador Multi-Agente**: Agentes integrados e especializados (Criação, Copywriting, QA Visual e Publicador) trabalhando juntos.
- **Geração de Imagens (Flux)**: Criação de banners comerciais de alta definição sob demanda via NVIDIA Flux API.
- **Marca d'Água Dinâmica**: Script local em Canvas para aplicação automática e limpa de logotipos na imagem.
- **Fila de Agendamento**: Calendário operacional integrado para controle de postagem e disparos automáticos.

### 🛠️ Tecnologias
- **Frontend**: React, TypeScript, Tailwind CSS.
- **Backend / Processamento**: Node.js, Llama 3.3 (copy), Llama 3.2 Vision (QA check), Flux/Imagen.
- **Banco**: SQLite para histórico e logs de agendamento.

## 🇺🇸 English

> **Multi-Agent AI Content Generator & Campaign Scheduler**

Automated pipeline for campaign planning, copywriting, and visual asset generation using collaborative AI agents.

### 🚀 Key Features
- **Multi-Agent Orchestration**: Specialized agents (Creator, Writer, Reviewer, Publisher) collaborate to produce posts.
- **Flux Image Synthesis**: Integrates NVIDIA Flux API to generate high-end marketing graphics (1024x1024).
- **Dynamic Watermarking**: Client-side Canvas script that overlays corporate branding before deployment.
- **Campaign Scheduler**: Integrated calendar queue to publish content at peak engagement times.

### 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS.
- **Backend / Engine**: Node.js, Llama 3.3 (copy), Llama 3.2 Vision (QA check), Flux/Imagen.
- **Database**: SQLite for history and scheduler logs.
